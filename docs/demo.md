# 2-Minute Hackathon Demo

**Opening:** A fraud transaction is rarely suspicious from one field alone. FraudShield combines context into a single, explainable decision.

**Demo:** Load risky demo → show BLOCK score → point to velocity, distance, new device and merchant risk → change the inputs to normal values → show ALLOW.

**Technical point:** The API is independent from the dashboard, so the same scoring endpoint can sit behind a payment gateway, mobile app or event stream.
